# Plan: Add a second test section (AI vs human-drawn images)

## Context

The quiz currently has one section: 5 side-by-side text passages where the user picks which was written by AI. We want a **second section of 5 image questions** (AI-generated image vs human-drawn art), running back-to-back with the text section in a single quiz with one combined results screen at the end.

User decisions:
- Section 2 = **AI image vs human-drawn art** (both are artwork)
- **Back-to-back** flow: text Qs → image Qs → video → combined results (no section divider screen)
- **5 image questions** (matches section 1, total 10)
- Image URLs are remote (Unsplash / Wikimedia Commons) as placeholders the user can swap later

The cleanest design is a **single unified `PAIRS` array with a `type` field** ("text" | "image") rather than a parallel array. The current question/answer/results loop is already type-agnostic about A-vs-B picks — only the rendering needs a fork on `type`.

## Approach

1. Extend `PAIRS` items with a `type` field. Existing text items get `type: "text"`. Add 5 new `type: "image"` items where `human` and `ai` hold `{ url, attribution }` instead of `{ text, attribution }`.
2. Add a render fork in `renderQuestion()` and `renderResults()` so image items inject an `<img>` into the existing `.passage` / `.side-text` containers.
3. Change the question prompt per type: "Which one was written by AI?" (text) vs "Which one was made by AI?" (image).
4. Order: text first, then images, shuffled within each subsection so the user always sees "section 1 → section 2".
5. Add minimal CSS for image rendering inside cards and breakdown.

No new screens. No changes to consent / video / results flow. Existing `answer()`, scoring, and `show()` are untouched.

## File-by-file changes

### `quiz.js`

**Data model** (lines 4–71): keep the array but add a `type` field. Append 5 image items. Image item shape:
```js
{
  type: "image",
  genre: "Portrait" | "Landscape" | "Still life" | "Surreal" | "Abstract",
  human: { url: "...", attribution: "Artist, Title (year)" },
  ai:    { url: "...", attribution: "Generated by AI" }
}
```
Mark existing 5 items with `type: "text"`.

**Order construction** (line 103): replace the single shuffle with:
```js
const textIdx  = PAIRS.map((p,i) => p.type === "text"  ? i : -1).filter(i => i >= 0);
const imageIdx = PAIRS.map((p,i) => p.type === "image" ? i : -1).filter(i => i >= 0);
state.order = [...shuffle(textIdx), ...shuffle(imageIdx)];
```
This preserves "all text questions, then all image questions" while shuffling within each.

**`renderQuestion()`** (lines 112–131):
- Read `pair.type`.
- Update the prompt element (new id `prompt-text` — see HTML change) to "Which one was written by AI?" or "Which one was made by AI?".
- Helper `renderSide(container, data, type, isPoetry)`:
  - `type === "image"`: set `container.innerHTML = ''` then append `<img class="passage-image" src="${data.url}" alt="">` and toggle `.passage` → `.passage.image`.
  - `type === "text"`: clear classes, set `container.textContent = data.text`, toggle `.poetry`.
- Call it for both `text-a` and `text-b`.

**`renderResults()`** (lines 144–199):
- In the breakdown loop, branch on `pair.type`. For image items, render `<img class="side-image" src="${data.url}">` inside `.side-text` instead of text. Attribution line stays the same.
- The score-calculation loop (lines 145–150) is unchanged — it only checks A vs B picks.

### `index.html`

- Quiz section (line 37): give the prompt an id so JS can update it.
  - Change `<p class="prompt">Which one was written by AI?</p>` → `<p id="prompt-text" class="prompt">Which one was written by AI?</p>`
- Pick labels (lines 40, 45): leave "Passage A" / "Passage B" — they read fine for either type, and changing them per question would add UI churn. (If the user later wants "Image A / Image B", that's a follow-up.)

### `styles.css`

Reuses existing `.pair-grid`, `.pick-card`, `.pair-side`, `.breakdown-item` — no changes needed there.

### Image URLs (placeholders the user can swap)

For the human-drawn side I'll use Wikimedia Commons URLs of public-domain paintings (Van Gogh, Hokusai, etc.) — these are stable and clearly "human-drawn art." For the AI side I'll use Unsplash URLs of digital/generated-looking artwork as visual placeholders; attribution will say "Generated by AI" so the *answer key* is correct even though the URL is a stock photo. The user can drop in real AI image URLs later by editing only `quiz.js`.

I will NOT hotlink to sites with ambiguous licensing; only Wikimedia Commons + Unsplash.
