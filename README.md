# AI or Human? — A Reading Quiz

A short interactive quiz that asks the reader to identify whether each of 10 short passages was written by a human (public-domain literature) or generated by AI.

## How to run

Open `index.html` in any modern browser. No build step, no server, no dependencies — all the passages are embedded directly in `quiz.js`.

## What's inside

- `index.html` — three screens (title, quiz, results) toggled by a CSS class.
- `styles.css` — typography and layout.
- `quiz.js` — the 10 passages plus the quiz state machine (shuffle → render → answer → score → retake).

## The passages

Five genres, two passages per genre (one human, one AI):

1. Literary fiction — Jane Austen vs. AI
2. Detective fiction — Arthur Conan Doyle vs. AI
3. Essay / opinion — Henry David Thoreau vs. AI
4. Nature writing — John Muir vs. AI
5. Poetry — Emily Dickinson vs. AI

All human passages are public domain. The AI passages were generated by Claude and deliberately matched in length, genre, and register to make the comparison fair.

Passage order is reshuffled on every retake.
